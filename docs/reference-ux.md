# Референс качества (запись экрана владельца, 12.11.2026, 28 с)

Источник: питомец Codex (корги). Кадры — `.ref/sheet_1..4.png` (локально, в git не кладём: это чужой UI).
Берём **уровень качества и сценарий**, не внешний вид один в один: своя лошадка, свой UI.

## Покадрово
| Время | Что на экране |
|---|---|
| 0–1 с | Сидит (idle). Под ней маленькая «ручка»-полоска. |
| 1–2 с | Наведение → под питомцем всплывает пилюля с кнопками: ✎ «написать» · 🎙 «голос». |
| 2–5 с | Тащат мышкой за тело → анимация бега/прыжка, морда смотрит по направлению движения; пилюля едет следом. |
| 6 с | ✎ → пилюля превращается в поле ввода: «+» (вложение), плейсхолдер «Начать новый чат», круглая кнопка отправки (серая, пока пусто). |
| 7–14 с | Печатают — кнопка становится синей; поле растёт до 2 строк. Питомец сидит, наклоняет голову, моргает (живой idle). |
| 15 с | Отправили → пилюля ✎ · 🎙 · ˅ (свернуть) + карточка статуса: жирная первая строка = текст запроса с «…», серая вторая = «Запуск чата». |
| 16–18 с | Вторая строка «Размышление…». Заголовок меняется на сгенерированное название задачи: «Найти последние новости Яндекса». |
| 19–26 с | Тащат за тело (курсор-«рука») → бег влево/вправо; статус живой: «Чтение safety.md» (текущий шаг агента). |
| 27 с | Весь виджет ≈ 460×290: питомец + пилюля + карточка. |

## Требования к нашей лошадке (из референса)
1. **Графика:** иллюстрация-стикер (тёмный контур, объёмная заливка), не пиксель-арт. Плавные кадры: idle (моргание, наклон головы), бег влево/вправо, прыжок, ожидание. Единый стиль всех кадров.
2. **Перетаскивание:** схватил за тело → лошадка скачет в сторону движения, UI едет вместе. Плюс автономные прогулки по краю экрана (хотелка владельца, в референсе нет).
3. **Наведение** показывает пилюлю ✎ · 🎙; вне наведения — только лошадка.
4. **Поле ввода:** «+», плейсхолдер, кнопка отправки серая/акцентная, многострочность, Enter — отправить.
5. **Карточка статуса после отправки:** заголовок задачи (сначала текст запроса, потом короткое название) + живая строка текущего шага: «Запуск», «Размышление…», «Чтение <файл>», «Выполняет команду…», «Ждёт вашего ответа», «Готово». Кнопка ˅ сворачивает.
6. **Окно** меняет размер: ~192×208 одна лошадка → ~460×290 с UI; клики мимо видимых элементов проходят насквозь; лошадку не обрезает краем окна при перетаскивании (в референсе на 6-м кадре обрезало — не повторять).
7. **Нативный вид macOS:** системный шрифт, белые пилюли с мягкой большой тенью, скругления, акцентный синий.

## Что это меняет в плане
- Плагин должен слать не только состояние, но и **текущий шаг** (`tool.call`: инструмент + файл/команда → человеческая строка) и **название задачи**.
- В референсе ввод **начинает новый чат**, а не пишет в открытый. Нужно выяснить, может ли плагин/приложение открыть новую сессию в десктопном Claude; иначе — пишем в последнюю активную сессию (текущий план).
- 🎙 голос и «+» вложения — после MVP.
