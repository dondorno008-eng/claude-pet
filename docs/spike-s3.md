# Спайк S3 — оверлей на Tauri 2 (macOS)

Дата: 12.11.2026. Ветка `spike/overlay`, код — `overlay/` (одноразовый, не прод).
Стек: Tauri 2.12.5 (`macos-private-api`), `tauri-plugin-single-instance` 2, `objc2-app-kit` 0.3
для NSWindow/NSWorkspace; фигурка — своя SVG+CSS лошадка (ассетов Codex нет).
Машина: Apple Silicon, macOS (Darwin 25.6). Сборка: `npm run tauri build` → `.app` + `.dmg`.

Как проверял. Физически кликать мышью и печатать агент не может (у терминала нет
Accessibility — `AXIsProcessTrusted=false`, синтетические клики macOS выбрасывает).
Поэтому:
- курсор двигал `CGWarpMouseCursorPosition` (работает без AX) — `verify/warp.swift`;
- окна и их уровни/прозрачность смотрел через CGWindowList — `verify/winlist.swift`, `verify/owners.swift`;
- снимки — только окна приложения (`screencapture -l <id>`), с альфой;
- клик/ввод — через «самотест»: второй запуск `ClaudePetSpike --selftest` приходит
  в первый экземпляр через single-instance и дёргает ТЕ ЖЕ обработчики, что и клик
  (`openInput`, `focus_input`, submit). Лог — `~/.claude-pet/overlay-spike.log`.

## П.8 подробно — карантин и Gatekeeper

Что делал (копии в `/tmp`, оригинал не трогал):
1. `spctl --assess -vv` на собранный `.app` → `code has no resources but signature indicates they must be present`
   (Tauri подписывает ad-hoc линкером: `flags=adhoc,linker-signed`, `Sealed Resources=none`, без TeamIdentifier).
2. **Вариант Б — скачать `curl`:** раздал `.dmg` с localhost, скачал `curl` → у файла только
   `com.apple.provenance`, **`com.apple.quarantine` нет**. Смонтировал, скопировал `.app` → запустился, работает.
3. **Карантин как у Safari** (`xattr -w com.apple.quarantine "0083;<hex-время>;Safari;"`):
   `open` → rc=0, процесс стартует из `AppTranslocation/...`, но не доходит до `setup()` (в логе нет `started`)
   и умирает за ~2,2 с. Прямой запуск бинарника → `exit 137` (SIGKILL). Отчёта о падении нет.
   Окна-диалога Gatekeeper (CoreServicesUIAgent) в списке окон нет — **ни диалога, ни сообщения**.
4. **Перподписал ad-hoc целиком** (`codesign --force --deep -s -`): `codesign --verify --strict` — `valid on disk`,
   `spctl` — `rejected`. С карантином — то же: тихо умирает, диалога нет.
5. Системный журнал (`log show`, syspolicyd) из этой сессии не читается (возвращает пусто) — **точную
   формулировку отказа Gatekeeper не видел**. Видел ли владелец что-то на экране в момент пп. 3–4 — не знаю.

Вывод: пользователь, скачавший `.dmg` браузером, получит «молча не открывается». Пути:
- доставка через `curl` (установщик плагина/скрипт) — карантина нет, работает;
- либо `xattr -dr com.apple.quarantine ClaudePetSpike.app` после копирования;
- либо подпись Developer ID + нотаризация (99 $/год) — единственный путь для «скачал в браузере и открыл».

## Не проверено (нужны руки владельца, ~5 минут)

1. Фуллскрин: развернуть любое окно на весь экран (зелёная кнопка) — лошадка должна быть поверх.
2. Spaces: Ctrl+→ на другой рабочий стол — лошадка там же.
3. Живая мышь: навести на лошадку → пилюля; ✎ → напечатать текст → Enter → файл в `~/.claude-pet/inbox/`.
4. Сквозной клик: кликнуть в пустую часть окна рядом с лошадкой (в пределах ~460×300) — клик должен попасть в приложение под ней.
5. Потаскать лошадку мышью — разворачивается по направлению.
6. Открыть скачанный браузером `.dmg` — что именно покажет macOS (если вообще покажет).

## Находки по ходу

- `NSApplication.deactivate()` фокус не возвращает — нужно запоминать фронтовое приложение и активировать его обратно.
- `window.is_focused()` сразу после `set_focus()` даёт `false` (асинхронно) — проверять фокус в JS (`document.hasFocus()`).
- Тикер должен читать флаг «тащим» ПОСЛЕ сна, иначе первый тик таскания включает сквозные клики.
- CPU ~17% ядра при ходьбе — для постоянного питомца много; кандидаты: реже двигать окно (сейчас 30 Гц), ходить эпизодами, а не всё время.
- inbox общий с S1 (`~/.claude-pet/inbox/`): тестовые файлы S3 (`test-*.json`) мог подобрать плагин S1. Свои файлы удалил.

## Вердикт

**Tauri 2 годится — идём.** Прозрачность, поверх всех, без Дока, ходьба, ресайз под пилюлю/карточку,
посегментный сквозной клик, таскание с разворотом, ввод с фокусом и возвратом фокуса, single-instance —
работают; `.app` 4 МиБ, `.dmg` 1,8 МиБ. Два риска для плана: (1) раздача — без Developer ID скачанный
браузером `.dmg` молча не запускается, ставить через `curl`/скрипт или снимать карантин;
(2) CPU при постоянной ходьбе ~17% ядра — заложить экономный режим. Ручная проверка п.2/4/5/10 — список выше.
