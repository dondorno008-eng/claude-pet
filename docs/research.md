## Codex Pets (OpenAI)
- Официальная фича, запуск ~1–2 мая 2026 в Codex app (macOS/Windows); позже — Codex CLI (0.167.0, 06.11.2026) и ChatGPT desktop/web. В IDE-расширении нет. Docs: https://learn.chatgpt.com/docs/pets
- Это индикатор статуса в плавающем окне поверх всех окон, не тамагочи: 4 статуса — Running, Needs input, Ready, Blocked (приоритет Needs input > Blocked > Ready > Running). Роста, редкости, звуков не найдено.
- 8 встроенных питомцев, команды `/pet`, `/hatch`; хоткей Option+Space / Win+Alt+P.
- Свои питомцы: скилл `hatch-pet` (openai/skills) генерирует по описанию. Формат: `~/.codex/pets/<имя>/pet.json` + `spritesheet.webp`, атлас 1536×1872, сетка 8×9, кадр 192×208; анимации idle, running-left/right, waving, jumping, failed, waiting, running, review.
- CLI-часть открыта: `codex-rs/tui/src/pets/` (Kitty graphics / Sixel / iTerm2 ≥3.6, не работает в tmux/Zellij). Код десктопного оверлея закрыт.
- Реакция: нравится ненавязчивый мониторинг задач; ругают баги оверлея, «Clippy без пользы», заслоняет кнопки. Issue #60477: локальные питомцы уехали в облако (claim одного пользователя).

## Что брать для своего питомца
1. Хуки Claude Code → локальный файл/сокет с токеном → панель-рендерер.
2. Карта состояний как у Codex: работает / ждёт подтверждения / ошибка / готово.
3. Совместимость с форматом пака Codex (pet.json + атлас 8×9) — сразу тысячи готовых питомцев.
4. Без патча бинарника и без accountUuid.
5. Питомец вне цепочки разрешений; установка с бэкапом настроек и удалением только своих хуков.
