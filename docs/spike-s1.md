## Что ещё всплыло

- Нет горячей перезагрузки `--plugin-dir` в этих сессиях (`plugin-dir watch: watching nothing`): после правки мода сессию надо перезапускать.
- `$.prompt.submit` из мода проходит мимо своего же хука `prompt.submit` (`skipped: re-entry`), остальные плагины его видят.
- После `/clear` id сессии меняется без `session.start`: мод перечитывает id по `session.end` reason `clear` и переносит файл (поле `continuedAs` / `continuedFrom`). Оверлей должен идти по этой цепочке.
- Побочные эффекты прогона: доверие к папке worktree записано в `~/.claude.json` (диалог trust принят); в сессии B ушёл набранный ход «2/exit» (ответ на вопрос о полноэкранном режиме не совпал с экраном).
- Живых ходов: около 9 без модели (первый прогон) + 3 с моделью haiku (второй прогон).
- Bash-хук владельца RTK (`PreToolUse`, «RTK auto-rewrite») сам разрешает переписанные им команды: для `grep` в отладке `Hook PreToolUse (rtk hook claude) returned permissionDecision: allow (reason: RTK auto-rewrite)`. `echo hi` тоже прошёл без диалога (кем разрешён — не разбирал). Диалог вызвала `touch`. Для проверки «ждёт ответа» нужна команда, которую никто не разрешает заранее.
